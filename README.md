# .NET Universe

A graduation project built around a practical .NET application workflow.

The project focuses on the parts of an application that are easy to overlook but important in real systems:

- search
- validation
- filtering
- pagination
- structured application flow

## Why this repository exists

This is one of my earlier projects, kept as part of my engineering history. It represents the transition from coursework toward building software with clearer application structure and user-facing behavior.

## Engineering notes

The project is intentionally simple. The value is in understanding the request flow, keeping responsibilities separated, and making common data operations predictable.

**Archive / learning project.**
